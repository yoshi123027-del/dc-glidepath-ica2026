# 再現性ガイド

## 原則

最終日本語版の分析は、英語版と同様に、元論文の数値計算アルゴリズムを固定し、較正パラメータだけを変更します。参照アルゴリズムは `02_adopted_analysis/01_reference_algorithms/` に格納しています。

## パラメータ変更

`02_adopted_analysis/02_final_parameters/final_parameters.json` を参照してください。

主要な値は次のとおりです。

- `gamma_p = 0.14286739349365235`
- `gamma_d = 0.20613769531249998`
- `gamma_c = 0.12565490722656253`
- `rho_d = 2.5083699226379395`
- `theta_cp = 0.273138427734375`
- 共通終端平均 `70.34483966999646`
- MVS 図6: `gamma0 = 2.5`, `eta0 = 0, 0.5, 1, 2`

## 英語版との同一性

英語版の対応元は `dc-glidepath-ica2026-en` main commit `4f2535f343c05b6d2e6cef01782fde3b50b5ca0a` です。

数値計算コード、パラメータ、基準CSV、図1〜図6の計算定義は英語版と一致させます。日本語版で変更するのは、README・説明文・図中ラベルなどの自然言語だけです。

## 検証ルール

新しい再計算結果は、`03_adopted_results/` の基準ケースとMVSの要約に数値誤差の範囲で一致した場合にのみ採用します。その後、再計算された出力から論文用図を生成します。

## 履歴・ボツ案

`90_rejected/` は、日本語版リポジトリの整理前の図・結果・スクリプト等を監査用に残す場所です。現行論文の再現元には使用しません。
