# DC Glide Path ICA2026 — 日本語照合用リポジトリ

このリポジトリは、2026-08-15 時点の **英語版 `dc-glidepath-ica2026-en` の採用済み分析を、日本語で確認するためのミラー**です。

## この日本語版の役割

英語版の内容に数値・ロジック上の誤りがないかを日本語で照合できるよう、次のものは英語版と同一に固定します。

- 数値計算アルゴリズム
- 較正パラメータ
- 基準結果CSV
- 図1〜図6の計算定義
- 感応度分析・数値診断の計算条件

**異なるのは自然言語の説明だけです。** README、コードブック、ステータス、再現手順などは日本語訳しています。

英語版の対応元は commit `4f2535f343c05b6d2e6cef01782fde3b50b5ca0a` です。
