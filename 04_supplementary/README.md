# 補足分析

論文の補足的な感応度分析は、採用済みの同一パラメータを使用しますが、方向性を確認するロバストネスチェックとして、元のスクリーニング設計 (`N_t = 80`) を維持します。

対象となる感応度は次のとおりです。

- 安全な終端資産 / `D_T`
- 無リスク金利 `r`
- リスク資産期待収益率 `mu`
- リスク資産ボラティリティ `sigma`
- 拠出プロファイル

これらはロバストネスのスクリーニングであり、月次 (`N_t = 480`) の主結果を置き換えるものではありません。採用した参照アルゴリズムと、検証済みのパラメータのみ変更ワークフローから再計算してください。
